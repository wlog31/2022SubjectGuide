# 2022 개정 교육과정 고등학교 과목 안내서

정적 HTML 사이트입니다. 서버 빌드 과정 없이 `site` 폴더 전체를 정적 호스팅에 배포하면 됩니다.

- 시작 파일: `index.html`
- 계열 정보: `tracks/index.html`
- 학과 정보: `departments/index.html`
- 교과 정보: `subjects/index.html`
- 과목 상세: `courses/course-001.html`부터 `courses/course-290.html`
- 교과/계열 소개: `sections/`
